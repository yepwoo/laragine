| **Supported Laravel Versions** | **PHP** |                 |
|--------------------------------|---------|-----------------|
| 11.x                           | 8.2+    | end of life     |
| 12.x                           | 8.2+    |                 |
| 13.x                           | 8.3+    |                 |

> Laravel 11 reached end of life, and its tagged releases carry an unpatched
> security advisory that Composer blocks by default. Laragine still supports it,
> but upgrading to 12.x or 13.x is recommended.

> Laragine 2.x supported Laravel 8.x–11.x on PHP 7.4+. If you are on Laravel 10 or
> earlier, stay on the 2.x line.

We developed Laragine to make the software development using Laravel faster and cleaner, so you can get things done faster, not only that, Laragine is not about quantity only, it's all about quantity and quality.
